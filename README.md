# Delfino Modern – GitHub Pages 005

Komplette statische Verkaufsdemo für Eiscafé Delfino.

Enthalten:
- responsive Landingpage für Smartphone und Desktop
- moderne mobile Navigation
- klickbare Gelato-, Pizza- und Pasta-Karten mit direktem Sprung zur passenden Speisekarten-Kategorie
- moderne Speisekarte mit Kategorien und Filter
- Online-Bestellbuttons zum bestehenden Delfino-Bestellsystem
- Anrufen im mobilen Menü statt störender zweiter Bottom-Bar-Aktion
- Impressum, Datenschutz und 404-Seite
- eingebettetes CSS und JavaScript, damit auf GitHub Pages keine Stylesheets verloren gehen

Diese Variante enthält bewusst kein PHP/WordPress. GitHub Pages kann PHP und WooCommerce nicht ausführen.
