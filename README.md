# Delfino Modern – GitHub Demo v007

Diese Version ist eine rein statische Verkaufsdemo für GitHub Pages.

Neu in v007:
- Keine Weiterleitung mehr auf die alte Delfino-Bestellseite.
- Speisekarte und Demo-Bestellung laufen direkt auf `speisekarte.html`.
- Produkte per `+` in den Warenkorb.
- Pizza-Größe 33 cm / 40 cm wird direkt abgefragt.
- Warenkorb mit Mengenänderung, Entfernen, Zwischensumme und LocalStorage.
- Abholdaten (Name, Telefon, Zeit, Hinweis) direkt im Warenkorb.
- Keine echte Übermittlung und keine Zahlungsmethode: der Abschluss ist ausdrücklich als Demo gekennzeichnet.
- Mobile und Desktop optimiert.

Für eine echte Kundenversion muss der letzte Schritt später an ein Backend/WooCommerce/Stripe o.ä. angebunden werden. GitHub Pages selbst kann keine sicheren Bestellungen oder Zahlungen serverseitig verarbeiten.
